# 개발자 확정 사항 (설계 문서보다 우선)

## 2026-11-18
- **Rojo는 코드만 관리**: 맵(Workspace)과 차 모델(`ReplicatedStorage.VehicleModels`)은 Studio에서 직접 관리한다.
- **맵**: Claude가 그레이박스(회색 뼈대) 맵을 생성기로 만들고, 어색하거나 안 이어지거나 겹치는 곳은 개발자가 Studio에서 직접 손본다.
- **차 물리**: 레이캐스트 서스펜션 방식.
- **모바일**: 운전용 화면 버튼 UI를 따로 만든다.
- **레이스 주기**: 5분마다 투표. 진행 중인 레이스가 있으면 끝난 뒤 60초 후로 미룬다 (`GameplayConfig.Race`).
- **레이스 참여 방식**:
  1. "참여"를 누르면 레이스 로비 공간으로 이동한다.
  2. 로비에 동그란 원이 있고, 원 안에서는 플레이어끼리 부딪히지 않는다.
  3. 로비에서 탈것을 고른다.
  4. **그 탈것에 탄 채로 원 안에 있어야** 레이스에 참여된다.
- **최대 8명은 동승자 포함 사람 수.** 관광버스를 꽉 채워 오면 그만큼 자리를 차지하는데, 그것도 개그라서 감수한다.
- **주행 수입**: 속도에 따라 적게 또는 많이 번다.
- **오토(방치) 방지**: 맵에 빙빙 도는 구간을 적게 두고, 같은 구역을 반복하면 수입을 줄인다 (`EconomyConfig.Driving.antiAfk`).
- **레이스 보상**:
  - 꼴찌라도 완주하면 보상을 준다. 참여 인원이 많을수록 더 많이 준다.
  - 솔로 레이스나 짧은 코스는 보상을 줄인다.
  - 튜닝 차이에 따른 매칭 보정은 여전히 없다.
- **동승자 머리 때리기**: 레이스 중 허용 여부는 보류 (`passengerHeadBonkInRace = false`).
- **내 차 권한 설정**: 운전 권한과 동승 권한을 각각 "모두 / 친구만 / 나만" 중에서 고른다. 차를 뺏어 타는 것을 막기 위한 설정이다.

- **8명 초과 시 선착순**: 원에 (차 탄 채로) 먼저 들어온 순서대로 자리를 잡는다. 출발 전에 원에서 나가면 (실수든 일부러든) 자리를 잃고, 대기 중이던 다음 사람이 그 자리를 채운다. 다시 들어오면 맨 뒤로 줄을 선다.

- **게임 안 글자는 나중에 전부 영어로** 바꾼다 (차 이름, UI, 알림). 지금 한국어는 임시. 코드 주석/문서는 한국어 유지.

## 2026-11-18 (레퍼런스 영상 이후)
- **레이스 두 종류**
  - **트라이얼**: 혼자 기록 경쟁. 오픈월드의 코스 출발 게이트를 지나가면 언제든 시작. 구간 이름이 표시되고, 구간마다 내 최고 기록 대비 +/- 를 보여 준다.
    - 고스트: 내 최고 기록 고스트, 또는 원하는 상대의 고스트를 골라서 같이 달린다. (상대 고스트는 저장 시스템과 기록 탭이 생긴 뒤에 연결)
    - **Backspace = 완전히 처음부터 다시.** 떨어지거나 뒤집혔을 때 복귀(R)는 마지막 체크포인트로.
  - **오픈레이스**: 모집해서 같이 하는 멀티 레이스 (기존의 5분 투표, 로비 원, 8명 규칙). 복귀는 마지막 체크포인트.
- **부스트 패드 없음.** 영상의 도로 위 노란 화살표는 코스 방향 안내 표시(인디케이터)일 뿐이다.

- **드리프트 탈출 부스트 없음** (부스트 중 방향 잡기가 어려움). 코드는 `DriftBoost.enabled = false` 로 꺼 둠.
- **벽 긁기**: 정면 충돌이 아니면 속도를 유지하며 벽을 따라 미끄러진다.

- **오픈월드 폭발 후**: 3초 뒤 마지막 안전 위치(땅 위 똑바로 있던 곳)에서 차와 함께 부활, 운전자는 자동 탑승. 동승자는 래그돌에서 일어나기만 함.
- **내리기**: 속도가 12 이하일 때만 (운전자/동승자 모두). 내리면 운전석 왼쪽 빈 공간 → 막혀 있으면 오른쪽 → 앞 → 뒤.
- **좌석**: 운전석만 E 프롬프트, 동승석은 닿으면 바로 앉음 (권한 없으면 내려놓음). 동승자는 점프로 못 내리고 F/버튼으로만.
- **벽 긁기 연출**: 벽에 붙어 달리면 계속 불똥, 벽에 긁힌 자국(12초 뒤 사라짐), 차 옆면에도 긁힌 자국.
- **트라이얼 중 폭발**: 지금은 트라이얼 취소 (Backspace 로 다시). 레이스(오픈레이스)는 마지막 체크포인트 부활로 만들 예정.

- **아바타: R6** (래그돌이 더 웃기고 가벼움). Studio Game Settings → Avatar → R6.
- **폭발 연출**: 박은 순간 정지(히트스톱, 하얀 화면, 파티클/카메라 멈춤) → 콰앙 → 위 + 진행방향 뒤로 포물선, 관절 완전히 풀린 래그돌 (땡깡 휘적은 꺼둠).

- **오픈월드 먼저, 레이스/트라이얼은 나중** (트라이얼은 `Trial.enabled = false` 로 꺼둠).
- **도로망**: 바깥 큰 순환 고속도로 + 가운데 큰 O 자 도로 + O 자에서 고속도로로 가는 갈림길 4개 + 서쪽 큰 우회로. (`src/tools/RoadBuilder.luau`)
- **월드 리워크 (약 3000×3000, WORLD 0.6)**: 중앙 도시(O 자 도로 + 십자 도로 + 빌딩 + 딜러샵, 스폰) → 사방 4개 도로 → 바깥 큰 순환 고속도로
- **고갯길 산 (북서쪽)**: 꼭대기 약 700, 구간마다 성격이 다름 (완만 스위퍼, 급한 헤어핀, 가파른 직선, S 시케인, 쉬는 구간, 연속 헤어핀)
- **길이 서로 막지 않게**: 자동 다리, 자동 입구(가드레일/테두리선 비움), 갈림길 기울기 펴기, 경사 상한 16°(끊김/너무 가파름 방지), 도로 위 지형 깎기, 길 아래는 지형(Terrain)
- 도시 도로는 가드레일 없음
- **섬 월드 (최신)**: 개발자가 보여준 참고 지도의 "구성 요소"(해안 도심, 해변/부두, 강과 다리, 설산 고갯길, 서킷, 공항, 숲, 사막 협곡)만 가져오고 배치는 오리지널로 새로 짬. `src/tools/IslandBuilder.luau`. 이전 맵 생성기(RoadBuilder)는 그대로 남겨 둠.

## 2026-11-18 (방향 전환: 차량 PVP) — 아래 내용이 위 레이싱/오픈월드 결정보다 우선
- **장르**: 큰 아레나에서 차끼리 싸우는 PVP. 운전수 + 보조수(총/폭탄/아이템).
- **게임 모드**: 팀 데스매치, FFA(팀원 정해서). 정해진 시간이 지나거나 목표 킬 수에 도달할 때까지 부활하며 싸움.
- **피해 주는 방법**: 차끼리 박아서 차 HP 깎기, 장외로 밀어내기, 보조수가 총으로 차 HP 깎기, 상대 운전수/보조수를 직접 쏴서 죽이기.
- **운전수가 죽으면**: 그 차는 운전 불가(비활성), 시간이 지나야 부활.
- **보조수가 죽으면**: 공격 불가, 부활할 때까지 운전수가 무빙으로 버텨야 함.
- **혼자일 때**: 보조수를 고르면 봇이 운전, 운전수를 고르면 봇이 보조수.
- **무기**: 보조수, 운전수 모두 상점에서 무기를 골라 삼.
- **맵 아이템**: 먹으면 버프 (체력 회복, 이동 속도 증가 등).
- **맵**: 기존 맵(섬/오픈월드)은 모두 버림. 둥근 깔때기 모양 아레나, 가운데가 장외, 갈림길 여러 개.
- **갈림길 경사로**: 끊기지 않고, 고리길을 가로막지 않게 고리 옆에 나란히. 폭은 차 7대가 가볍게 지나갈 정도로 넓게 (지금 100). 나머지 세부 모양은 개발자가 맡김. (`src/tools/ArenaBuilder.luau`)
- **착지 데미지**: 똑바로 바퀴로 착지하면 데미지 없음. 코박기/옆으로/뒤집혀 떨어질 때만 데미지 (`Health.landingUprightDeg`).
- **통제 불능 = 물리에 맡김**: 해봤더니 차가 혼자 자빠져서 **꺼둠** (`Physics.Chaos.enabled = false`, 예전 물리 그대로).
- **범퍼**: Attribute `Bumper` 붙은 파트(회전 쟁기)에 닿으면 "통" 하고 진행 방향 반대로 살짝 튕김, 데미지 없음 (`Physics.Bumper`).
- **난간 없음**: 경사로 노란 난간도 전부 없앰 (언제든 박아서 넘길 수 있게).
- **바깥도 장외 가능 + 캠핑 방지**: 바깥 벽은 전부 없앰 (안쪽 구멍처럼 어디서든 떨어짐), 고리마다 천천히 도는 회전 쟁기가 차를 밀어서 떨굼.
